## 坐标、单位和控制器模式

内部长度用 mm、角度用 rad。Toolpath 位于 `workpiece_build`，机床轴位位于 `machine`；后处理把 A/C 转为 deg。自有机型的 A±π、C±2π 来自论文设备表，其余线性行程、速度/加速度、回转中心、零偏和轴正方向没有标定证据。

论文核心离线方言固定 `G90`、`M83`、`G94`，并在结束前恢复三种模式。转位前的绝对 `Z=20 mm` 与切刀流程中的相对 `Z+20 mm` 分开记录。固件版本、G93 支持、T0—T3 宏文件和协调 XYZAC 能力仍未知，因此生成 NC 标记为 `offline_only`，可用于严格回读和审查，不能直接下发机床。

## 材料与事件

材料区域由用户显式指定，区域只引用已声明的 `material_id/channel_id`。通道变化按 `prepare_pause → retract → cut → park → switch → load → temperature_wait → purge → prime → resume` 形成结构化事件。第一条 T 命令计入选择次数，不计入有效通道变化；同一通道连续区域不重复选择。沉积体积和清洗长度分别统计。

传感器未到位、温控超时、通道缺失、未分配区域、模式恢复失败和严格回读失败均阻止可执行导出。取消发生在发布前时保留上一份有效结果。输入、参数、材料计划或控制器契约变化后，已有结果进入 Stale。

## 独立真值边界

解析直管/圆弧管、解析圆柱/圆锥、矩形 trimmed face 和当前 Curve 精确边长继续作为独立真值。论文时间、耗材和厚度数字只作为历史实验描述；没有原始重复测量时不设为 PC06 软件验收阈值。历史 NC 不作为当前几何或材料量真值。
