# 五轴切片器离线产品交付计划

日期：2026-09-23。任务编号 PRODUCT-01。目标是在真实桌面界面中完成“载入 STEP → Setup → 选择工作台和几何角色 → 生成 → 检查预览 → 导出 G-code → 严格回读 → 保存、重开项目”的操作闭环，并让首次使用者能照图操作。验收对象是可交付的离线切片软件；目标机床标定、控制器宏、实机碰撞和试打仍需现场资格，不能把 `machine_executable=false` 改写成可上机。

## 当前基线和范围

- 仓库 `master` 的 `69569be` 已交付弯管、校徽、叶轮、三叶扇的模型、新旧 NC、对比图和路径数据；四份新 NC 的历史全流回读通过。历史结果只用于定位，不代替本轮 GUI 验收。
- 三类 Freeform 实体操作已进入公共领域命令和产品链。历史 GUI 生成/导出记录覆盖校徽、叶轮和三叶扇；弯管做过四角色鼠标拾取。跨工作台作业持久化、完整四例从头操作、长任务取消响应、中英多尺寸和首次使用说明尚需验证。
- 本轮先覆盖现有 Planar、Curve、Rotary、Tube、Freeform 入口和四个真实示例。Research、第二机型、任意拓扑自动分类、实机发布功能保留清楚的禁用入口或扩展接口，不用空白成功页暗示已经实现。
- 用户可以提供新测试模型；现有解析夹具和四个真实 STEP 足以启动排查。只有发现覆盖缺口时才下载许可清楚、尺寸适当的新公开模型。

| P3 示例矩阵 | 弯管选管体与入口/出口边；校徽选球面实体；叶轮选叶片面、对面和根边；三叶扇选 hub、叶片和根面。每例从原生打开/重开到导出 | 每例有实际点击记录、参数与选几何记录、结果图、导出清单、SHA-256 和全流回读；与旧 NC 比较工序及覆盖，不以视觉相似充当合格 |

P0/P1 使用很小的解析 STEP，先解决界面问题。叶轮和三叶扇沿用已有项目与历史输出做静态对照；只有相关代码或参数变化后才各运行一次完整百万点生成。生成期间记录阶段耗时和 UI 是否可操作，避免仅靠长时间等待判断进度。

## 产品停止线

PRODUCT-01 只有在以下条件同时满足时才标记完成并停止目标模式：一个首次使用小模型和四个真实示例均经实际桌面点击完成可复现的选几何、生成、预览、导出及重开；导出 NC 完整回读通过且无未解释的几何/材料/轴语义错误；界面加载、长任务响应、错误恢复和教程图片已核对；保留接口的功能不会被误认为已可用。若某示例经证据确认超出现有算法支持范围，应明确拒绝导出并记录缺口，不能把拒绝称为成功切片。实机资格继续由单独现场验收决定。

## 面向使用者的文案规则

UI、首页、README 的使用入口和 `docs/guides/` 教程只描述可用功能、点击路径、输入要求、结果判断、限制与处理办法。不得出现 P01/FAN15 等研发阶段编号，也不以“本轮修复”“历史验收”“开发进度”“截图证据”等过程性叙述代替使用说明。阶段编号、失败记录、来源与验收证据留在 `docs/planning/`、`docs/reviews/`；教程需要注明画面性质时，直接写“示意图”“错误状态”“实际界面截图”。交付前搜索全部用户入口，并抽查中英界面与链接的教程正文。

教程编写检查项：每节给出使用目标、当前按钮和参数单位、可迁移的判断规则、真实点击步骤、正常/错误恢复、结果图和能力边界。图片优先用当前界面实拍；错误或 Stale 状态须标清，不能当作成功画面。案例数值可以展示，但须明确仅适用于该案例；用户应按自有设备、喷嘴、材料、装夹和试验结果重新确定。模型 ID、坐标、点数和轴范围同样只能作为练习值，不能要求新用户照抄。保留截图来源、日期和清单在内部验证目录；教程正文只写用户需要观察的内容。公开图片应遮蔽密钥、用户名和设备敏感值。

## 工具与成本

Computer Use 用于真实点击与截图；项目已有脚本/HTTP/pytest 用于快速定位和可重复回归；GitHub 与公开官方文档用于核对来源。插件清单中当前没有比这些工具更直接的切片能力，因此不为本任务安装无关插件。简单格式核对可批量运行；几何策略、机床姿态和验收判断保留人工逐例审查。测试只在输入、源码或环境变化后重跑受影响案例。
