# 第二代离线产品收尾计划

日期：2026-09-25。对应台账任务：`PRODUCT-01`。本文件规定第二代余下的产品工作和停止条件；实际状态仍以[开发进度台账](progress_tracker.md)为准。

## 1. 交付范围

第二代交付现有 Planar、Curve、Rotary、Tube、Freeform 五个工作台，以及公共制造设置、几何选择、路径预览、离线 NC 六件套、严格回读、项目保存重开和中英文使用说明。软件对新模型应沿用相同的操作和检查链；示例 ID 与数值只能用于教学，不能写成通用机床参数。

Research 工作台、物理/机床运动仿真和视频输出列入第三代，不作为本计划的通过条件。路径预览不称为物理仿真。真实控制器、机床/夹具标定和现场试打单独验收；离线通过不能自动把 `machine_executable=false` 改为可上机。

交付形式先以可安装的 Python 包和明确的 Windows 启动步骤为准。独立免 Python 安装器若需纳入第二代，应另定范围和验收标准，不用现有 wheel 冒充安装器。

## 4. 执行顺序与证据规则

1. 先冻结第二代范围和发布方式，给 V2-01 建立点击矩阵。使用小 STEP 排查界面，不用百万点案例反复定位按钮问题。
2. V2-01 通过后处理 V2-02。一次只跑需要验证的完整模型；定位失败时优先用最小反例，修复后再回到受影响案例。原始 NC/STEP 与新输出按工序、覆盖和姿态核对，不以一张相似的整体图代替路径检查。
3. V2-03 根据 V2-02 的实测耗时和卡顿安排。已有路径预览和 NC 回读可复用；需要改渲染或后台任务时先保留取消、Stale、导出资格的原有语义。
4. V2-04 与界面复核同步拍摄，但最终图片必须来自稳定的当前界面。截图原件、方法和失败记录归内部证据；用户教程只保留操作所需内容。图片不能遮盖错误状态或把未生成画面标为成功。
5. V2-05 使用最终提交重新核对。每项证据标明源码版本、输入/设置、运行环境及结果；历史测试数字只作基线。文档或图片单独改动不重跑整件 NC，但要重查链接、图像和用户文字。

## 5. 第二代停止条件

只有 V2-01 至 V2-05 的完成判据均满足，且没有未解释的核心 Error，才把 `PRODUCT-01` 标记为“已完成”。若某种拓扑超出当前算法范围，界面应明确拒绝并写出适用条件，不把拒绝称作成功切片。现场参数与效果继续以用户设备调试为准；第三代 Research/仿真保持单独计划。

本计划依据现有台账、交付复盘、教程文件和 2026-09-25 的只读图片审计编制。本轮没有重新运行五工作台界面闭环或完整 NC，也没有替换图片；以上“待验收”不能解读为新增失败结论。实施时更新唯一台账，并把对应证据与简短复盘放入 `docs/reviews/`。

- 当前微小接缝问题按第7节登记后停止新增精细采样、补偿算法研究和候选模块；除非出现新的核心失败证据或用户重新要求，不重启该专题。
