## 每例必须执行的操作测试

加载真实模型 → 进入对应工作台 → 选择边/面/实体 → 绑定入口、出口、导引或基底 → 核对方向及几何引用 → 配置 PLA 参数 → 从工作台命令入口生成 → 检查状态和路径 → 导出回读 → 保存重开。

脚本通过现有选择接口和共享命令执行，不能仅调用底层生成器。Qt 控件测试检查“使用已选边”等绑定动作。Computer Use 实际检查模型拾取、选中高亮、按钮操作和窗口结果；脚本设置选择不能证明鼠标拾取正确。补测漏选、错误实体、反向边、过期引用和失败禁止导出。

恢复入口：四例离线 NC 均已完整生成、回读和成图。弯管四角色鼠标拾取已实际执行，出口内圆 0012 被正确拒绝，外圆 0014 已重选。三叶扇旧程序 Y 倾转候选仅作带标签的对照，新程序使用目标 AC 重新求解，禁止直接 B→C 替换。IPW 按用户约定暂缓，实机标定、动态限制和控制器宏保留。Computer Use 本轮无法读取应用清单，真实选边→切片复验不得写为通过。

## 通用完成要求

- 2026-09-21 用户明确暂缓碰撞争议，优先继续完整 NC 与离线检查。本轮允许生成带 `OFFLINE` 标识的检查文件；IPW 碰撞记录为 deferred，不改写为 passed，不改变生产导出门槛。离线文件需完整回读、输出哈希与检查范围。轴动态限值、实机标定及局部承接没有证据时分别保留，不能把回读通过描述成所有制造检查通过。

- 2026-09-21 用户明确：目标机床物理轴按论文 AC，软件默认输出 A/C，轴字允许自定义。参数优先采用 `example/manuscript.docx`，缺项采用项目参考默认值，必要时核对 Open5X 来源并记录；参考默认值不视为实机标定。旧 EXAMPLE 的 B 按可能的 C 输出别名专项验证，不直接认定绕 Y 轴，也不全局替换原文件。无需等待额外配置才继续几何和离线产品开发。

- 基底、首层、层面族、生长方向、喷嘴轴分别明确；CAD 未来材料不能作为已打印承托。
- 图来自真实生成路径或新 NC 回读，公共坐标、全部范围、抽样及隐藏空移明确；保留旧 NC，不补画曲线。
- 修改层域、填充、姿态、合并或后处理后，必须实际重切对应完整示例，检查完整沉积图、空移图和诊断结果；可导出时再回读 NC。单元测试通过不能替代重切；检查拒绝导出时保留完整路径诊断图，明确未通过项，禁止先称修好再等用户发现路径错误。
- 旧代码比较先核对单位、模态、轴序和注册，再比较工序覆盖、局部形状、内部填充及异常连接。单向最近距离不等于制造资格。
- 失败逐个定位，必要时检索官方资料，记录来源与适用范围。先跑最小失败集，再跑相关回归，Qt 串行。
- 离线参考机型、真实机床标定及实机验证分别报告。未确认的控制器/喷头尺寸不编造，未通过不发布为可上机程序。
- 原 FAN07—FAN14 未满足条件时保留状态，四例局部通过不自动关闭 FAN15。
