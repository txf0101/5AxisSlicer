# 扇叶完整程序 FAN01—FAN05 实施复盘

> 2026-09-20 后续纠正：FAN04 的工艺验收已撤回。原平面截层体积与单点 FK 数据作为历史数值证据保留，不能证明绕中心柱起印和径向曲层生长。FAN02 的旧 NC 填充分工序结论也在复核，禁止用全文件 TYPE 标签证明叶片填充。见[纠正复盘](2026-09-20_fan_radial_correction.md)。

日期：2026-09-20。范围为制造输入契约、旧程序与 CAD 基线、完整作业依赖、固定 A=90° 的叶片全体积层域，以及公共壳层和内部填充分区。底座完整路径、三片叶片路径、统一后处理、GUI 和最终 G-code 属于 FAN06—FAN14，本轮没有生成新的完整扇叶程序。

## 完成内容

`manufacturing/fan_job.py` 增加了带来源的工艺参数、四实体稳定引用、Source→Build 变换、离线与实机资格分离、作业 DAG、语义哈希、下游失效传播、JSON 重开和原子发布槽。论文值、用户指定值、工程默认值、待实测值分别保存。喷头包络、机器零点和控制器宏版本为空时，契约允许离线研究并禁止宣称实机就绪。

独立基线脚本逐行扫描 186,891,627 字节的旧手工程序，没有调用产品 G-code 解析器。结果为 2,936,410 行、2,924,765 条运动和 2,893,775 条正挤出运动。类型统计包含 44,690 条 Sparse infill、2,799 条 Internal solid infill、82 条 Gap infill 正挤出运动。旧代码已经包含内部填充，后续比较应关注 CAD 覆盖、feature 归属和材料量，不能按“旧代码只有外壳”设定真值。2026-09-20 的先前软件程序只有 303 行、133 条运动和 125 条正挤出运动，也没有层变更标记，仍属于有限叶片路径。

真实 STEP 识别为三个约 6,773.126 mm³ 的叶片实体和一个 18,610.778 mm³ 的轮毂实体。固定 A=90° 后对 `body_001` 以 0.2 mm 步长覆盖完整变换包围盒，共检查 616 个层位，其中 466 层有材料；首末有效层之间没有空层。截面积积分得到 6,755.487 mm³，相对 CAD 体积误差 0.2604%。64 段与 128 段采样对照的最大面积变化为 0.00265%，刚性映射 Jacobian 为 1，未发现自交，独立三角函数 FK 复算的位置与角度误差均为零。该结论支持固定 A=90° 的离线几何路线，喷头扫掠和实体机床可达仍由 FAN09 与现场资格验证负责。

真实扫描暴露了两类截面恢复问题。一个共享顶点的曲线端点修正量为 0.00253 mm，超过旧默认 0.001 mm；另一个 OCCT Section 结果缺少闭合边，而相同实体与平面的 Common 材料面保持闭合。实现保留通用 Planar 的 0.001 mm 严格默认值，只在叶片层域显式使用 0.01 mm 上限，并在 Section 开放时回退到 Common 材料面。这个上限低于 0.02 mm 离散预算。原“相邻但不同顶点不可自动闭合”反例继续通过。

`feature_fill.py` 在同一层域上划分多道壁、顶底实体层、稀疏填充、实心填充、空内部和薄壁。解析测试覆盖带孔区域、多岛、0%/20%/100%、相邻层换向、顶底层覆盖和 0.6 mm 窄区。孔洞由偶奇裁剪保留，壁层耗尽内部区域时返回 `thin_wall`，不会叠加相交填充线。

## 验证与失败记录

项目专用 Python 3.12.7 预检通过，依赖版本和 QSettings 可写性满足要求。第一次扩大领域回归时，222 项用例通过，26 项在 pytest 系统临时根目录创建阶段统一触发 WinError 5。改用仓库内独立 `--basetemp` 后，同一集合 248 项全部通过。最终直接集 20 项通过。`scripts/check_quality.py` 完成 Ruff、迁移与安全规则、格式、上下文预算和 165 个源码文件的 mypy 检查。

机器可读证据在 `docs/reviews/evidence/2026-09-20_fan_complete_program/`。失败 JUnit、成功 JUnit、真实层域、旧程序统计、契约和作业 JSON 均保留，详细哈希见该目录的 `validation_manifest.json`。

## 取舍与后续

当前层域采用刚性 A=90° 后的平面截交，已经证明真实叶片实体可形成连续材料层域，并未生成最终沉积路线。FAN06 需要把公共 feature 分区接入轮毂全高路径和支撑逐层调度。FAN07 需要把同一分区映射到单叶片三维沉积路径，核对实际道距、根尖封闭、壳层占据和材料体积。完成 FAN08—FAN10 后才能得到三片叶片与底座合并的完整程序。

电脑模拟用户点击安排在 FAN12。当前尚无完整作业 GUI，提前点击只能验证旧入口，无法证明本轮新增作业流程，所以本轮未调用电脑工具执行产品验收。
