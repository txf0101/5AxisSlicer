# 工作台任务阶段门槛

开始或关闭 5AxisSclicer_V2.0 的台账任务时使用本表。只应用与当前编号和改动范围有关的项目。

## 任务开始

- 当前任务的依赖已完成；台账状态、日期和证据链接是当前版本。
- 工作区现有修改已识别，不覆盖用户或其他任务的更改。
- 支持输入、拒绝输入、坐标、单位、控制器和真实设备边界已写清。
- 需要外部算法经验时，检索任务已限定到具体问题，来源准备登记到 `reference_research.md` 或专项来源文件。
- 正常样例、边界样例和失败样例可获得；缺失真值会影响正确性时先完成真值任务。

## 契约与算法

- 几何引用能稳定保存、重绑，并在拓扑漂移时报告问题。
- 算法输出使用共享 Toolpath 和事件语义，来源与参数哈希可追溯。
- 解析真值或独立测量验证几何；测试没有复制实现公式充当唯一证据。
- 路径顺序、接缝、空移、材料体积和失败诊断可核对。
- 轴位、速度、加速度、奇异、限位和 FK 回代按任务影响检查。
- 喷嘴、基体、夹具和已打印体的检查范围与近似方法明确。

## 产品闭环

- GUI、受限脚本和 HTTP 通过同一命令入口修改领域状态。
- Generate、Cancel、Ready/Warning/Error/Stale 和旧结果保留行为正确。
- Viewer 直接读取生成路径合同；G-code 回读是独立核对步骤。
- 导出包含 `main.gcode`、`toolpath.json`、`machine_axes.csv`、`warnings.json`、`preview.json` 和 `manifest.json`，或记录该任务为何不产生其中某项。
- 保存重开、输入变化、引用重绑和格式迁移按改动范围验证。

## UI 与手册

- 参数名称、单位、范围、默认值、帮助和禁用原因与领域模型一致。
- 中英文文本不遮挡；代表性窗口尺寸下按钮、滚动区和问题列表无碰撞。
- 正常流程与错误恢复均有真实操作证据；截图不把错误态描述成成功态。
- 当前模块图文手册和文档索引已更新，旧状态说明已清理。

## 测试与证据

- 已按 `five-axis-slicer-validation` 选择解释器、串行 Qt 测试和停止条件。
- 直接相关测试、质量门禁及必要回归结果已记录，skip 与未验证项单列。
- 输入、关键产物、源码或清单指纹可核对；临时产物不伪报为长期归档。
- 任务复盘记录来源、判断、取舍、首次失败、修复、限制和可复用方法。
- `progress_tracker.md` 更新状态、证据、下一步、日期及本轮 Skill 调用。

## 阶段完成

- 所有直接依赖任务都已满足判据；没有用入口、单张截图或最小演示替代完整工作台。
- 阶段支持范围内的正常和失败案例矩阵均有结果。
- 生成、检查、回读、导出、保存重开、双语 UI 和图文手册形成闭环。
- 参考机型、真实控制器、真实机床和现场试切的状态分别表述。
- 完成后停止重复验证，进入台账指定的下一项。
