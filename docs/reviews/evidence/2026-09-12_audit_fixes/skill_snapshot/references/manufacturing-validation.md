# 制造验证经验

来源：5AxisSclicer_V2.0 的 `docs/reviews/2026-09-12_algorithm_audit_fixes.md` 与同日 `evidence/2026-09-12_audit_fixes/`。本页用于生成、验证、回读与算法阶段收尾；普通 UI 文案修改无需运行真实模型矩阵。

## 坐标与资格

- 分清 Source→Build 的几何变换、显示 Model CS、Workpiece→Mount 的静态装夹与 IK 旋转。至少用非零平移和旋转对照核对机器轴，并独立 FK 回算，避免漏变换或重复旋转。
- 输入指纹覆盖源文件内容、几何引用、坐标、机型、喷嘴、材料、装夹、操作及算法版本。生成前、发布前、恢复和导出时核验；途中改参不得发布旧上下文。纯显示变化不使制造结果失效。
- 检查器改变资格含义时升级产品版本，旧资格转 Stale 并保留参数和旧预览。完整已应用 Setup 与轻量几何预览的前置条件分开。

## 独立检查与反例

- 回读检查完整 NC 指令流，覆盖单位、绝对/相对模式、E 初始化、逐段材料、事件顺序、进给和终止位置；额外未标记运动也要拒绝。用改 E、改模式、删事件、插入运动的反例验证，不能只检查带标记坐标。
- 路径端点通过不能证明整段道宽包络或空移通过；连续 Z 路径需检查中间高度的真实实体。有限采样报告步长和覆盖范围，不称为连续扫掠证明。
- 总材料量正确仍可能掩盖不同区域或段的正负抵消。按区域比较实际指令材料与独立目标，累计逐段绝对偏差；几何覆盖、搭接和材料体积分别报告。
- 容差来自几何近似、单位和制造要求，不能为放行失败结果反向放大。窄壁参数可能必须拒绝；稀疏对照必须注明未覆盖比例，不能代替实心填充资格。
- 截交闭环优先依据共享拓扑与有向连接恢复。端点修复须有上限；真实缺口、分支与大偏差仍拒绝。AUD-02 的 1 μm 端点上限和 0.001 mm 包络容差仅属于该实现，不直接套用到其他算法。
- 碰撞报告区分目标 CAD、夹具、基体、已打印体和完整喷嘴。静态保守障碍检查不能证明零件与支撑联合逐层调度；前级失败时未执行的后级检查不得计为通过。

## 真实样例与交付

- 从项目样例选择有声明壁厚、道宽、层高和装夹的正常/失败输入；局部切层通过后，阶段资格还需覆盖声称支持的全高范围。保留实际六件套、禁止导出的反例及参数。
- UI 用真实生成结果检查长 Error/Warning、Stale 和恢复；中英文及代表尺寸下同时检查字段自然高度、标题、滚动可达性、状态与导出按钮。按钮不碰撞仍可能存在表单被长诊断压扁，需看实际截图。
- 记录最终源码/输入/产物指纹及测试所对应版本。并发任务修改后按实际影响补验证；保留首次失败与被撤回资格的旧证据，显式标明最终替代版本。
- 全仓测试通过证明回归状态；制造正确性还需独立真值和真实模型证据。严格拒绝不可靠输入可关闭已确认的漏检缺陷，但不能因此关闭尚未实现的自适应道宽、联合调度或真实设备资格。
