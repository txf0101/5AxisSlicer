# 自有机型默认配置与文件管理复盘

任务 I01-OWN，2026-09-12。用户授权将自有打印机设为默认，并在型号栏选择、自定义及导入其他机器配置。本轮不执行 I01 全部第二机型算法任务。

使用的 Skills：five-axis-workbench-development、five-axis-slicer-validation。模型与推理强度沿用当前任务设置；精确 token 不可得。

## 实现与判断

将论文设备参数保存为随包 JSON，默认机型排列在内置列表首位。新建桌面项目选用自有机型，首次 STEP 导入保留已选配置；切换新模型使用新的默认 Setup。加载已有项目按资源快照恢复，不改写旧机型。共享 Setup 继续服务 Tube 与 Planar。

复用 UserResourceLibrary、MachineProfile 校验及既有 set_machine 命令。新增自定义 JSON 编辑并另存、导入与导出入口。导入和另存分配新用户 ID，避免覆盖内置或现有用户条目；选择后点击应用才改变当前 Setup。非法或异种文件格式拒绝，原选择和项目保持不变。

自有配置保留论文工艺参考和来源，机型对象使用已知台面与旋转限位。未知 XYZ 行程和动力学上限为 null；零偏、回转中心、零姿态和台面厚度的零／单位变换只为未标定建模占位，完整 JSON 和界面注明未标定。reference_only 保留，未加入伪造的市售品牌配置或通用格式转换。

工艺参考随自有配置文件保存、导出；本轮没有把150 mm/s强制写入所有操作，也没有把换料动作自动插入后处理。材料、喷嘴和工序继续采用各自配置入口。

## 验证过程

使用 tmp/pytest9/Scripts/python.exe；技能预检依赖及 QSettings 可写性通过。Qt 串行运行。首次专项63项中62通过、1失败：旧测试对默认已选机型重复应用仍要求一次刷新，现为无变更操作；测试改为选择不同机型后验证刷新。首轮质量门禁指出机型模块超过行数上限2行及后续格式问题，压缩模块说明并格式化，未放宽门禁。

后续专项35 passed、1 error：新测试使用 pytest 默认临时目录遇到 WinError 5；改用项目内独立 --basetemp 后，自有机型专项6 passed。全仓729 passed、3 skipped、130 subtests passed（344.28 s）；3个skip均为Windows符号链接权限不足。全仓后仅调整自有机型双语显示简称，以解决下拉框截字，受影响专项再次6 passed；最终质量门禁全部通过，Mypy覆盖120个源码文件。
