# 分阶段模型与 token 预算复盘

日期：2026-09-11
范围：T01—I04 共 44 项待实施和验收任务；不含已完成的 Q00、B01—B03、A01—A03。

本轮把模型选择与任务风险绑定。清晰、重复的工作使用 Luna，日常编码使用 Terra，复杂几何、运动学和研究判断使用 Sol，Astra 只承担少量阶段门和总验收。这样保留独立检查，同时避免每个任务都使用最强模型。

预算按输入、推理和输出总 token 的悲观上限估算。七个未完成阶段基础上限合计 29.50 M，另留 20% 即 5.90 M 风险储备，项目总上限 35.40 M。该数值不是历史实测，也不等同于费用或 Credits；后续有产品实测数据时，应按阶段实际值更新估算。A01—A03 在本轮规划期间已完成，因此只保留后续维护的模型规则，不占未来额度。

主要取舍是把较多预算留给 Tube、Freeform 和 Research。Tube 建立后续复用基础，Freeform 的修剪曲面和投影存在较多数值歧义，Research 需要独立审查基线与结论边界。Planar、Curve 和 Rotary 应复用已有契约、几何及运动链，预算相应收紧。

节省 token 的关键做法是按编号提供精简证据包、将机械任务下沉到低成本模型、限制 Astra 调用点、禁止无新证据的重复尝试，并在累计达到阶段预算 80% 时复核范围。当前局限是 Codex 产品未必向每轮提供精确 token，因此实际值可能只能记录为不可得；不得用文本长度替代实测。

模型角色依据：[OpenAI Codex Models](https://developers.openai.com/codex/models)，访问日期 2026-09-11。模型可用性受账户和发布批次影响，若指定模型不可用，按 Luna→Terra→Sol→Astra 的能力层级选择同级可用项，并在任务证据中记录替代原因。
