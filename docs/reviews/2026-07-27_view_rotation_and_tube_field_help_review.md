# 2026-07-27 预览上下旋转与 Tube 字段帮助复盘

## 1 现场问题与实施边界

用户在中文 Tube 工作台复核 `pipe2` 时发现两处直接障碍：默认模型预览的左键上下旋转方向不符合使用习惯；喷嘴“安装接口”等专业字段缺少输入含义，用户无法判断应填螺纹、热端名称还是其他数据。

修改前只读核对 `圭臬/开发目标文档.docx`。文件大小为 492214 字节，修改时间为 2026-07-06 13:45:16，与前一轮实施记录一致。本轮没有写入该文档。中心线、分块、切层、路径生成、逆运动学和 NC 输出仍在既定后续范围。

## 2 上下旋转方向的证据与修正

Qt 鼠标坐标向下为正。Bambu Studio 固定提交 [`12f17b06f4f537f9c03162d08bb70cf733c42839`](https://github.com/bambulab/BambuStudio/tree/12f17b06f4f537f9c03162d08bb70cf733c42839) 中，[拖动增量](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GLCanvas3D.cpp#L5810-L5859) 会传入[球面相机旋转](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Camera.cpp#L481-L521)。正屏幕 Y 增量提高其轨道仰角。

VTK 适配器现有正 `Elevation` 已符合该方向。OpenGL 原方向式把方位角混入世界 Z 高度，修正单个符号只能保证默认方位；相机绕到侧面时，纵向拖动会退化为水平轨道。当前实现统一为 Z 向上的球面轨道：方位角绕世界 `+Z`，历史 `_pitch` 字段按从 `+Z` 起算的天顶角解释，屏幕向下增量减小天顶角。前、后、左、右、顶、底标准视图同步换算，平移、缩放和拾取状态机保持原行为。

定向测试覆盖 0°、90°、180°、270° 四个方位，检查向下拖动均提高相机世界 Z 高度，反向拖动恢复原角度；另有标准视图方向和 VTK 正 Elevation 合同测试。该模型保留 1° 极点保护，避免视线与 `+Z` View Up 共线。

## 3 字段帮助合同

Tube 帮助文案集中保存在 `tube_ui_text.py`，没有向全局 `ui.py` 增加工作台分支。每个绑定控件同时设置 Qt 原生 `toolTip`、`statusTip` 和 `accessibleDescription`。动态 Part 角色与坐标候选使用 `Qt.ToolTipRole`，Model CS 和 Build CS 切换时重新计算数值输入基准说明。实现依据来自 Qt 5 官方的 [`QWidget::toolTip`](https://doc.qt.io/qt-5/qwidget.html#toolTip-prop)、[`QWidget::accessibleDescription`](https://doc.qt.io/qt-5/qwidget.html#accessibleDescription-prop) 和 [`Qt::ToolTipRole`](https://doc.qt.io/qt-5/qt.html#ItemDataRole-enum)。

帮助覆盖 Part、Machine、Nozzle、Material、Model CS、Build CS、Placement、视图切换、状态门禁和问题列表。说明内容围绕输入对象、单位、参考基准、提交后果与未知值处理组织。标签、输入框和辅助接口共用同一文本。语言切换会按稳定资源 ID 及坐标候选的 `kind/entity_id` 恢复当前选择，未应用的字段值和待确认状态继续保留。

## 4 喷嘴数据一致性

“安装接口”现显示为“安装接口（螺纹/型号）”，占位示例为 `M6×1 螺纹 / 厂家接口型号`。该字段属于自由文本机械接口标识，当前校验只判断是否为空，界面明确说明程序没有执行接口兼容性推断。

内置喷嘴 Profile 的 `length_mm` 为 `None`。旧页面却预填 18.000 mm，容易把编辑初值误当成模板或厂商数据。当前最小值显示“未填写”，用户需要依据图纸或实测输入。R–Z 坐标约定同步写入 `NozzleProfile`：喷尖为 `Z=0`，`+Z` 指向安装端，总长取最远轴向安装端。

喷嘴选择框现在会回填所选 Profile 的接口、总长和外形状态，切回内置身份模板时清空未知字段。编辑器只在字段发生变化时创建用户副本；单独修改总长不会再被忽略，编辑接口时会保留已有的实测 R–Z 外形，也不再凭空写入 `project-defined` 材料和 `standard` 流量类别。

页面仍可生成两点式简化碰撞外形。提示语明确其半径来自喷孔直径经验公式，当前只写入资源快照，不渲染外形，也不运行碰撞检查。R–Z 校验现要求每点恰有两个有限值、半径和 Z 非负、首点为喷尖 `Z=0`、Z 非递减、存在正轴向跨度，最大 Z 与总长一致，喷尖外半径不小于喷孔半径。已有外形时修改总长会被拒绝，避免静默沿用过期轮廓；物理字段改变后清除旧来源归属。

`Setup Ready` 仅表达资源字段完整，不构成碰撞安全或可执行 NC 许可。后续正式碰撞链仍需记录外形来源和近似等级，并加入热端、加热块、线缆与机床部件的安全门禁。

项目格式当前尚未区分程序生成的简化外形与用户提供的实测外形，二者均保存为 `outer_profile_rz_mm`。结构有效的 v2 旧快照仍可加载；物理外形不符合现行约束时，喷嘴节点按安全失败原则降为 Invalid。界面已明确数据用途。后续扩展应增加 `generated_approximate`、`user_supplied` 和 `legacy_unspecified` 等来源语义，对近似和历史未知数据持续给出 Warning。

## 5 交互完整性与测试过程

坐标分量确认后再修改数值时，页面会标记该分量待确认。旧行为允许直接点击“应用”并提交先前引用，画面数值与持久状态可能不一致。当前应用入口会拒绝含未重新确认分量的草稿，并给出中文或英文提示。“取消”会恢复上次已应用的候选和值、清除待确认状态，并移除 controller 草稿。

新增定向用例覆盖 OpenGL 上下旋转、喷嘴编辑副本、未知长度、Profile 切换、双语帮助、状态栏说明、无障碍描述、Part 下拉项、Model/Build 数值基准、六自由度字段、坐标重新确认，以及 R–Z 轮廓的负半径、NaN、Inf 边界。

## 6 可复用资产与工程判断

字段帮助已形成声明式合同：一个领域字段对应双语说明、状态栏文本、无障碍描述和下拉项提示。Planar、Rotary 与 Freeform 后续接入 Setup 时可复用这套绑定方式，数值参考基准仍由各工作台的动态上下文提供。

本轮的关键判断来自“提示是否与数据行为一致”的交叉审查。检查悬停文案时发现未知长度伪默认、模板切换串值、单独修改总长丢失、坐标确认后编辑仍可提交等问题，并把它们收敛到资源构造和提交边界。该方法比逐个添加提示词更容易形成可验证的产品契约，也为后续物理资源审计留下清晰入口。

## 7 “未填写”状态的键盘输入修正

桌面使用中发现喷嘴总长显示“未填写”时，单击后直接输入数字没有反应。复现表明 `QDoubleSpinBox.specialValueText` 会把中文状态文字留在编辑器中，普通单击只放置光标，随后输入形成非法文本并被数值校验器拒绝。原测试仅调用 `setValue()`，未覆盖真实键盘路径。

当前使用共享的 `OptionalDoubleSpinBox` 处理可空数值：焦点进入或鼠标释放时，若控件仍处于最小值状态，则选中完整状态文字，下一次键盘输入直接替换。新增 Qt 测试按“单击、输入 `12.5`、回车”复现用户动作。喷嘴与 Tube UI 专项回归为 56 passed，质量门禁和差异格式检查通过。
