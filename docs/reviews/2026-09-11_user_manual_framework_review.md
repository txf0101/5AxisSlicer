# 图文使用手册体系复盘

日期：2026-09-11

## 本轮解决的问题

现有文档可以分别查到启动、坐标设置、脚本和算法验收，但已完成的 Tube 三种操作缺少一份连续的用户流程，G-code 可视化也没有独立手册。坐标指南仍写着路径生成和 NC 尚未开放，与 T08—T12 当前状态不一致。

本轮建立 `docs/guides/README.md` 作为使用手册入口和编写规则，新增 Tube 工作台与 G-code 预览两份中文图文手册，更新坐标指南、根 README、开发计划和进度台账。后续工作台只有在对应算法可用时才编写正式操作说明，避免用设计计划描述尚未存在的按钮和结果。

## 图片和内容依据

Tube 手册复用坐标指南的五张真实界面图，并引用 T08—T12 的三尺寸中英文 UI 证据。三张操作页截图保留 Setup 缺失、过期或失败状态，正文已明确它们是布局和错误态示例。

G-code 手册固化了现有成果页四联图，以及本轮 pipe2 手工/程序路径对比和安全回读诊断图。pipe2 图同时记录几何接近与范围差异：生成环线到手工路径的最近距离中位数约 0.297 mm，但测试产物只有 7 个粗粒度截面，没有手工路径中的底座和完整管体。正式 Generic XYZAC 限位会使当前测试 NC 回退到 Machine XYZ，手册没有把恢复出的模型坐标路径写成安全回读结果。

## 取舍与可复用方法

- 使用手册与开发复盘分开维护。手册回答怎样操作和怎样判断结果，复盘保留测试、来源与实现判断。
- 固定图片进入 `docs/guides/assets/` 或引用带日期的 `docs/reviews/evidence/`，避免长期依赖被忽略的 `outputs/` 路径。
- 正常流程、错误恢复、三维结果和能力边界同时出现。界面截图如果含错误码，图注必须说明用途。
- 参数表从当前领域模型核对默认值、单位和约束。UI 或参数契约变化时，同一任务更新文字与截图。

## 检查和局限

本轮检查了新增及修改文档的本地 Markdown 链接，全部目标存在；三张新增 G-code 图片可以读取，Tube 图片来自既有验收证据。文档修改不改变算法或 UI 行为。

当前缺少 Setup 全部就绪后，三种 Tube 操作从生成中到成功导出的连续真人截图；已有三操作图片更适合解释布局和错误状态。后续 UI 发生相关改动，或形成真实参数的成功案例时，应补拍成功流程并替换手册对应图片。Planar、Curve、Freeform、Rotary 和 Research 尚未完成，其正式手册随各自阶段实现和验收补齐。
