# FAN15 四示例切片与旧程序对照

日期：2026-09-20。状态：验收未通过，逐例诊断。按用户最新要求提前执行 FAN15 独立示例检查，不据此跳过 FAN07–FAN14 的依赖验收。本轮没有修改生产算法，没有覆盖用户旧 G-code，也没有发布可上机的新总程序。

## 执行范围与口径

读取四份真实 STEP 和四份旧 G-code，记录 SHA-256；重新调用现有 Tube Indexed/Continuous、Freeform 领域生成器，并对四个完整模型执行 0.2 mm 全高度 Planar 诊断。使用 PLA 既定参数，道宽 0.4 mm、层高 0.2 mm、沉积速度 1200 mm/min。Planar 对照为两道壁、20% 内填充，特意作为几何诊断，不含支撑、顶底皮、完整运动和后处理资格；不能当作无支撑五轴方案。

每个高度均记录成功或具体拒绝，偏置异常和原边界回退在审计层显式拒绝。失败层不会取得资格；诊断数组可能保留该层失败前已生成的部分区域，图和计数不代表整层可打印。扫描上限沿用加载器保守包围盒，尾部空高度也计入请求数；不得把请求数等同于有效沉积层数。

旧程序采用显式模态 G90/G91、M82/M83、G92 解析，统计正 E 运动并保留行号。A/C 参考使用零中心 `Rz(-C)Rx(-A)`，不代替真实机床标定。未知 B/U/V/W 轴字使整份参考退回机器 XYZ，不混合两种坐标。G2/G3 和英制输入显式拒绝。PRINT_START、M98、SET_GCODE_OFFSET 等未展开宏不具备完整控制器执行资格。

## 已定位的算法及配置问题

1. **单道与完整体积混淆。** Tube 的 `path_radius_mm` 是内外半径中值，Indexed 和 Continuous 都围绕该半径生成一条道；不会因为输入是实体就自动填满壁厚。Freeform 的 `path_count`、`layer_count` 控制有限导引偏置，不提供全实体自动覆盖。此前示例生成报告只证明这些局部流程，不足以代表完整示例。
2. **多实体截面缺少材料并集语义。** `planar/region.py` 收集多个实体的所有轮廓后统一按嵌套深度判断孔，没有保留正材料实体归属。独立嵌套方块反例：10×10 与 4×4 实心截面联合面积应为 100 mm²，当前为 84 mm²。此失败以 strict xfail 保留，不能计为修复通过。复杂示例每个局部拒绝的具体原因仍需分开核验，不能全部归因于这一缺陷。
3. **偏置错误隐藏与窄壁回退。** 公共 `feature_fill.py` 把内缩异常转为空集合，并可能采用原几何边界作为壁中心线。此次审计预先执行各偏置并拒绝原边界回退，暴露失败层。修复需要区分真正耗尽、几何内核失败与需要自适应道宽的区域。
4. **采样变粗隐藏问题。** 校徽密采样拒绝、粗采样通过是收敛风险，不能采用粗采样作为完成条件。曲线段中间的道宽包络和修剪边界仍需独立检查。
5. **坐标与参考数据差异。** 三叶扇未知 B 语义禁止强行按 C 解释。校徽旧图脚本明确记录模型与旧参考的 180° Z 注册；本轮仅对此例应用该记录，未进行任意拟合。叶轮 CAD 控制包围盒达 Z70.4，但独立网格基体实际约 Z44，旧 NC 还含空移/宏和附加工艺；不能用包围盒差值直接推断切片误差。
6. **Continuous 喷嘴方向与本例轴向生长不符。** 当前 `_helix_points` 使用管壁径向的负法向作为喷嘴轴，产品链直接传给求解器。对竖直直管、从下向上的轴向生长契约，喷嘴应朝 -Z；独立直管反例返回径向轴，已记录第二个 strict xfail。旧弯管参考 C 恒为 0、A 随弯曲倾斜，不能用当前 Continuous 的几何螺旋外形相似证明工艺等价。这一判定针对本次自由生长管件，不能推广成所有有芯模径向绕印工艺都错误。

## 图与距离指标

每张图左侧旧程序、中间当前曲层/管件生成结果、右侧全高 Planar 诊断。图中明确未通过，隐藏空移，显示抽样比例。校徽旧程序橙色为原文件 Custom 标签，不能把标签当作完整图案的独立真值。

端点最近距离只作抽样定位，包含旧程序基底、裙边及可能的异常连接；它不是 Hausdorff 距离、道宽覆盖率或实体误差。单向距离小也可能只是新路径属于旧路径很小的一部分，因此同时列出新到旧、旧到新；未完成坐标确认时禁止给出该指标。

## 验证、工具和复用

### 后续修复顺序及恢复判据

1. 修复公共层域的正材料实体归属与并集，保留孔及不同材料接口；嵌套、相交、接触、互不相交四种解析实体矩阵均须独立量面积，嵌套方块恢复 100 mm²。
2. 偏置异常显式传播，耗尽区域与真正薄壁分开处理；原边界回退禁止制造发布。复跑四例所有已记录失败高度，保留首次失败。跨层皮肤、承接与道宽覆盖另验，几何通过不自动恢复 FAN05/FAN07。
3. 弯管先完成底座与管壁联合调度，再按 1.0 mm 实壁生成多道或经过验证的可变道宽；全壁体积、局部横截面覆盖和弯曲内外侧承接同时核验。Indexed/Continuous 两种法向与旋转运动分别对照，不能只比较轮廓。
4. 校徽按全部文字/图案实体建立球面制造域、完整导引与有限道宽填充；同一配置由粗到细采样收敛，保留修剪边界反例。叶轮按实际基底与叶片接口建立共形生长域，补全八片叶片的实体填充。
5. 三叶扇先确认旧 A/B 的物理映射、零点和偏移宏，独立回算；新工艺按真实承托面分区。无支撑五轴与固定姿态带支撑方案分别验收，不混用完成标签。
6. 各例形成实际完整 Toolpath、机器轨迹、非沉积连接、喷头/已打印体检查及总 NC 回读后，才保存可重开项目、模型旁的新代码和最终路径图。未知控制器/实测机床资格继续分开报告。
