# 五轴运动仿真规划复盘

日期：2026-09-20。任务编号：SIM00。本轮完成资料调研、现有代码核对、技术路线、开发计划和独立台账，没有修改产品代码、安装依赖、启动GUI或生成视频。

当前项目已有全量G-code timeline、播放控件和跨工作台 `MachineAxisTrajectory`，运动仿真应直接消费这些合同。主要新增工作集中在机床部件树、关节到部件变换、确定性时间采样、逐帧渲染和视频发布。

LinuxCNC Vismach最接近床台/喷头模型需求，证明简易几何与外部STL可以共同组成关节机床场景；其GPL实现不直接复制。FreeCAD与CAMotics偏减材或三轴，用于交互对照。PyBullet具有关节和碰撞能力，但首版采用它会引入第二套场景和渲染链，因此只保留为后续独立碰撞后端候选。当前项目已使用VTK，选择VTK渲染帧、FFmpeg可选编码能减少架构分叉。

计划把内置参数化AC机床放在自定义模型之前，使坐标、时间、倍速和导出先有可复算真值。自定义床台和喷头模型单独处理单位、局部坐标、哈希与碰撞简化。32×和165×按时间映射实现，视频导出逐帧确定计算，不依赖GUI实时定时器。

限制包括当前Windows环境是否支持稳定离屏VTK仍需SIM05实测；FFmpeg不可假定存在，也不在本轮自动安装；动画不能证明现场碰撞安全、控制器插补或真实轴动态。
