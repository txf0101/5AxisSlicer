# 四类完整实体切片方法说明（教程素材）

状态：2026-09-21 的离线算法与完整 NC 已验证；三类实体填充已接公共 Freeform 操作及命令链，校徽完成一次真实 GUI 生成/导出，另外两类仍缺完整界面验收。[图文点击教程](quickstart_clickthrough_zh.md#5-freeform曲面与实体)给出当前界面入口与资格边界；本文记录可迁移的方法。产品化进度见[计划](../planning/fan15_productization_plan.md)。

## 1. 软件生成链的边界

完整 NC 的计算链为：

`CAD 与稳定几何角色 → 层域/填充 → GeneratedToolpath → 工序顺序与非挤出转移 → AC 逆运动学 → 后处理 → 严格回读 → 实际 NC 路径图`。

四例 NC 均由仓库代码执行该链得到，没有人工逐行编写运动。当前三类实体操作已由 Freeform 公共服务编排基体、特征与 NC；`scripts/run_fan15_solid_product.py` 只提供示例选择和参数。旧 finalizer 仍保留为历史对照，不能将其产物冒充新版 GUI 导出。跨工作台显式作业依赖和后台交互仍需补齐。

## 2. 按制造生长方式选择操作

| 几何和生长意图 | 候选操作 | 用户必须重新确认的输入 | 不适用情况 |
| --- | --- | --- | --- |
| 沿管中心线增长的恒定圆截面管体 | Tube Buildup/Continuous，加 Planar/CAD 基体 | 管体、入口、出口、基体、中心线方向、壁厚与道数 | 分叉管、显著变截面或无法建立单一中心线 |
| 同球心曲层上的凸起实体 | Spherical Solid Fill | 球心、基底半径、凸起实体组、径向厚度、上/下半球 | 一般双曲率面或多个球心 |
| 从受支撑根边沿修剪曲面展开并穿过实体厚度 | Surface Solid Fill | 每个实体的承载曲面、对面、根边、厚度方向 | 分叉面、非单调距离场、多值投影或根边不完整 |
| 围绕明确旋转轴从 hub 向外增长的叶片 | Radial Solid Fill | hub、每片叶片实体、根面、外面、旋转中心/轴、允许搭接 | 没有可证明 hub 承接、非径向生长或轴线不明确 |

模型外观相似不能决定模式。判断顺序是基底、首层接触、层面族、生长方向、喷嘴轴和机床旋转联动。

## 3. 共同参数及其含义

- 道宽决定有限材料覆盖，不应只把 CAD 边界当中心线。
- 层高用于基体 Z 层、球面径向层、曲面厚度层或叶片径向层；四者名称相同，物理方向不同。
- 路径间距必须在对应曲面的物理度量中检查。球面不能把平面图表距离直接当实长；一般曲面需沿面内距离场量测。
- 采样步长控制曲线离散，不能通过降低采样密度绕过 trim、自交或拓扑失败。
- 沉积、空移、回抽和安全间隙进入统一 Toolpath 事件；跨工序转移不得挤出。
- PLA 195/45 ℃来自当前参考配置，只是练习默认值；真实材料、喷嘴和机床需要重新标定。

## 4. 每个新模型的检查单

1. 用几何角色重新选择实体、面和边，不复制示例拓扑 ID。
2. 核对 Source、Build、Workpiece 和 Machine 坐标只变换一次。
3. 检查首层完整路径到真实已打印基底的距离，并把允许的半道宽搭接写入契约。
4. 检查逐层间距、最大段长、局部承接、壳/填充角色和分区材料量。
5. 合并全部工序后统一求解 AC，检查奇异、限位、累计旋转和非挤出转移。
6. 严格回读完整 NC 的坐标、进给、挤出和事件顺序，再由回读路径生成图片。
7. 报告碰撞、控制器宏、标定、动态限制和试切的实际状态；未执行项不能写为通过。

## 5. 已发现并需要长期保留的反例

- 扇叶固定 A=90° 后按平面层堆叠，会从无承托位置起印；叶根应沿 hub 表面形成有限道宽承接，再按正确层族增长。
- 三叶扇 STEP 的叶片和中心体存在约 0.5 mm CAD 间隙。算法需要显式搭接层，不能把 CAD 根面直接当成已接触。
- 球面和一般曲面只增加采样点不会补齐实体填充；必须生成有限道宽壳和内部路径。
- 旧 NC 的 B 轴和坐标宏未经标定时只能作为带标签假设；新程序从喷嘴姿态重新求目标 AC。
- 严格回读通过仍需核对最终落盘文件 SHA-256。Windows 文本换行转换会使“内存文本哈希”与实际文件不同。

## 6. 教程完成前还缺什么

- 三类操作的实体/面/根边按角色逐项鼠标拾取和错误恢复；当前界面可填 JSON 并从选中几何建立候选，但自动推断 hub/基体时需核对，不能直接信任最大体积启发式。
- 跨 Planar/Tube/Freeform 作业序列、明确转位和后台进度/取消资格。
- 叶轮、三叶扇、弯管等其余真实模型从界面选择、生成、导出和重开的证据，以及双语三尺寸截图。

已验证的校徽 GUI 路径：先配置完整 Setup（模型、零件、喷嘴、PLA、Model/Build 坐标和装夹），在 Freeform 新建 Spherical Solid Fill，选择球心、凸起实体组、基体实体并应用参数；重开项目后 Generate 得到 `warning` 离线结果，预览和导出六件套。测试夹具可由 `scripts/run_fan15_solid_product.py logo --prepare-project <目录>` 生成；它仅配置输入，实际生成仍需在界面点击。若出现 `complete enabled operation`，先核对操作的 Setup ID 与实际 Setup 是否相同。正式练习应重新选对应模型的实体角色，示例 ID 不可复用。

这些项目完成后，再把本文拆入学习总册的工作台选择、Freeform 支线、错误恢复和迁移练习章节。
