# 日常界面检查与复发定位

## 启动和资源

1. 记录候选说明、启动脚本、源码、资源的时间戳和 SHA256；核对清单后运行原入口。
2. 确认主窗口实际出现、包从候选导入、制造 Setup Schema 可用。若使用隔离副本补资源，保留原包失败证据与副本差异。
3. 修复交付时把所需 Schema 随候选根目录一起交付。预检须覆盖实际资源，启动脚本须传出应用失败退出码并恢复临时环境变量。
4. 文件格式、必需资源和失败退出码可用小型独立夹具核对；夹具不充当真实应用启动证据。

## 两个预览入口

| 页面 | 检查对象 | 易漏内容 |
| --- | --- | --- |
| 首页的 G-code 文件预览 | 文件、模型叠加、阶段分组、路径前缀、代码上下文、后台加载 | 只检查一组 0–7 不能证明任意子范围；三栏最小尺寸可能阻止真正缩窄 |
| Operation Session 的 Preview | 任意层上下限、图例、路径段属性、姿态、模型显隐 | 导入 NC 后可能跳到另一工作台；控件输入、摘要、滑块和几何需分别观察 |

页面隐藏或入口难找属于实际发现，不能据此省略要求的检查。先查可用入口，受阻时说明路径；只读任务中不自动修改导航。

## 最小操作矩阵

| 检查 | 输入与操作 | 判据 |
| --- | --- | --- |
| STEP | 小模型真实打开、FIT、旋转、缩放、模型显隐 | body/edge 统计和实体可见，视角改变，模型显隐不改路径 |
| 层识别 | 原八层见证；分别测试 `;LAYER:0`、`;Layer 0` | 不改原运动行也能识别八层 0–7；修改解析规则后旧缓存不能掩盖结果 |
| 实体料条 | 交互质量、旋转缩放、中文/英文 | 料条说明可读，FIT/ISO 和方向立方体不遮挡；说明的近似和宽厚来源保留 |
| 分组 | 超过 25 层的小输入，选择首、中、末组 | 图形与范围变化，末组非空；输入和源码行号对应 |
| 任意子范围 | 旧 Preview 输入 2–5、3–3，再恢复全部；交叉输入 5–3 | 数字框、实际范围、计数、进度和源行一致；模型遮挡时不能宣称几何已验证 |
| 路径进度 | 中间索引与末段 | 显示前缀、百分比、当前段和代码上下文联动 |
| 取消恢复 | 先得到缺 STEP 的 Warning，再开始较大文件并在进度出现时取消 | 原文件、几何、进度、选择来源和警告恢复；等待线程实际退出后有明确取消终态 |
| 重开 | 取消后从真实文件对话框打开原小文件 | 新请求成功，统计正确，既有警告仍可解释 |
| 布局 | 切换复选框两态、滚动图例和属性、中英文及代表性尺寸 | 两态外框和文字起点对齐；同一滚动布局中各区块不互相覆盖 |

随 Skill 提供的 `assets/preview_layered_infill_witness.gcode` 是 2026-10-02 原候选的显示见证，SHA256 为 `ae29c7d7a64d971651c5b82ce98f50c44c2286a1284afee6cf7a065db5594cc2`：8 层、280 空间段，其中 176 正挤出、104 非挤出。`assets/layer_range_52.gcode` 为合成显示输入：52 层、每层 4 段挤出和 1 段空移。它们仅用于离线显示检查，没有设备资格。

## 取消与生命周期

取消请求、恢复旧结果、工作线程退出分别记录。只保留旧几何但把 Warning 换成绿色 Ready，属于状态不一致。新请求替换加载中的旧请求时，仍应保存最近一份已稳定结果；过期请求的取消不得覆盖当前请求。

把“正在安全取消…”设置在发出取消请求前，避免立即回调的终态被随后覆盖。最终提示由实际线程结束信号驱动。受控线程测试可以区分请求阶段和退出阶段；Computer Use 的工具往返时间不能作为解析或取消响应时延。

## 图片与验证边界

- 实际截图大小与 Qt 逻辑大小分别记录。窗口 resize 被最小尺寸阻止时，文件名含 narrow 也不构成窄窗口证据。
- 必要时用真实候选控件做较窄视口补验，明确它与完整主窗口的区别。控件矩形不相交可以证明布局几何，不能代替像素可读性检查。
- 选中复选框的边框厚度会影响外框和文字布局；修复应核对两态真实几何。多区块被压缩重叠时，优先检查尺寸策略和滚动层级。
- Qt 测试用独立 QSettings INI；Windows 的映射索引文件需要在临时目录清理前关闭页面或释放句柄。Qt 用例串行执行。
- 只重复失败检查中发生变化的条件。直接测试已满足判据后停止扩展；发布前按仓库规则运行完整静态门禁并查看上传提交的 CI 终态。
- 记录候选测试模块的实际来源；独立原生扩展与 Python 包模块分开核对。历史性能数据、截图和测试结果只有代码、输入、环境吻合时才可复用。
